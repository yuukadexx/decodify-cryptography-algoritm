Masalah Umum & Solusi

1. Login Error 404

HTTP 404 - Page Not Found
  1. Clear cache browser (Ctrl+Shift+Del)
  2. Coba akses via mode incognito
  3. Reset password melalui email
  4. Jika masih error, hubungi support

2. Data Tidak Tersimpan

Error: Data not persisted
  1. Cek koneksi internet Anda
  2. Refresh halaman (F5)
  3. Export data sebagai backup
  4. Coba browser berbeda

3. Aplikasi Lambat

Performance Issue
  1. Clear cache dan cookies
  2. Tutup tab yang tidak perlu
  3. Cek koneksi internet
  4. Update browser ke versi terbaru

Error & Troubleshooting

Error Umum

Error 500 - Internal Server Error

Server mengalami masalah internal

  1. Tunggu 5 menit, refresh halaman
  2. Clear cache browser
  3. Coba akses dari browser lain
  4. Laporkan ke support jika berlanjut

Error 403 - Forbidden

Akses ditolak karena permission

  1. Pastikan sudah login
  2. Cek apakah fitur termasuk paket Anda
  3. Logout dan login kembali
  4. Clear cookies browser

Error Connection Timeout

Koneksi ke server timeout

  1. Cek koneksi internet Anda
  2. Nonaktifkan VPN jika ada
  3. Coba dengan jaringan berbeda
  4. Restart router/modem

Payment Failed - Transaction Declined

Pembayaran ditolak oleh sistem

  1. Cek saldo/limit kartu
  2. Hubungi bank/e-wallet provider
  3. Coba metode pembayaran berbeda
  4. Tunggu 15 menit coba lagi
