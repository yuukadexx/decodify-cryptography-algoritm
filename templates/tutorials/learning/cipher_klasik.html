📜 Pengantar Cipher Klasik

Cipher klasik adalah teknik enkripsi yang digunakan sebelum era komputer modern. Meskipun sederhana menurut standar sekarang, cipher-cipher ini membentuk fondasi kriptografi modern dan banyak yang digunakan selama ribuan tahun.

1. Caesar Cipher (100-44 SM)

Sejarah

Dikaitkan dengan Julius Caesar yang menggunakannya untuk komunikasi militer. Dalam bukunya "Life of Julius Caesar", Suetonius menyebutkan bahwa Caesar menggunakan cipher dengan geseran 3.

Demo Caesar Cipher

Hasil:
KHOOR
// Algoritma Caesar Cipher (JavaScript) function caesarCipher(text, shift, encrypt = true) { let result = ''; const direction = encrypt ? 1 : -1; for (let i = 0; i < text.length; i++) { let char = text[i]; if (char.match(/[A-Z]/)) { // Huruf kapital const code = char.charCodeAt(0); const shifted = ((code - 65 + direction * shift) % 26 + 26) % 26; result += String.fromCharCode(shifted + 65); } else if (char.match(/[a-z]/)) { // Huruf kecil const code = char.charCodeAt(0); const shifted = ((code - 97 + direction * shift) % 26 + 26) % 26; result += String.fromCharCode(shifted + 97); } else { // Karakter lain tetap result += char; } } return result; }

2. Vigenère Cipher (1553)

Penemu: Blaise de Vigenère

Meskipun ditemukan oleh Giovan Battista Bellaso, cipher ini populer dengan nama Vigenère. Digunakan selama 300 tahun sebagai "cipher yang tidak bisa dipecahkan".

3. Playfair Cipher (1854)

Teknik Matriks 5x5

Diciptakan oleh Charles Wheatstone tetapi dinamai menurut Lord Playfair. Digunakan dalam Perang Boer dan Perang Dunia I.

4. Mesin Enigma (1918-1945)

MESIN ENIGMA

Mesin enkripsi mekanik-elektrik yang digunakan Jerman Nazi dalam Perang Dunia II

Pemecahan oleh Alan Turing

Tim Bletchley Park yang dipimpin Alan Turing berhasil memecahkan Enigma dengan mesin "Bombe", memperpendek Perang Dunia II diperkirakan 2-4 tahun.

🎯 Kelemahan Cipher Klasik

  • Analisis Frekuensi: Huruf dalam bahasa memiliki pola frekuensi tertentu
  • Known-plaintext attack: Penyerang memiliki sampel plaintext-ciphertext
  • Brute-force
  • Kerumitan terbatas: Tidak didasarkan pada masalah matematika sulit
